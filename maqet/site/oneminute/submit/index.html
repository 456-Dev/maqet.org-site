Export a high-quality MP4

Same resolution and frame rate you shot and edited in. These settings look great on the big screen:

Container.mp4
VideoH.264, match source resolution (1080p or 4K) and frame rate
Bitrate1080p: 20–40 Mbps · 4K: 50–80 Mbps
AudioAAC, 48 kHz, 320 kbps, stereo
File nameFILMTITLE_TEAMNAME.mp4
Premiere Pro

File → Export → Media (Ctrl/Cmd+M). Format: H.264. Preset: Match Source – High Bitrate. Under Video, bitrate encoding VBR 2-pass, target 30 Mbps (60 for 4K). Export.

DaVinci Resolve

Deliver page → Custom Export. Format: MP4. Codec: H.264. Resolution and frame rate: same as timeline. Quality: Restrict to 40,000 Kb/s (80,000 for 4K). Audio: AAC, 320 kbps. Add to Render Queue → Render All.

Final Cut Pro

File → Share → Export File. Format: Computer. Video codec: H.264 Better Quality. Resolution: same as project. This saves an .mp4.

CapCut

Export (top right). Resolution: 1080p or 4K. Bitrate: Higher. Codec: H.264. Format: MP4. Frame rate: what you shot at.

iMovie

Share (top right) → Export File. Resolution: 1080p or 4K. Quality: High. Compress: Better Quality. Saves an .mp4.

Phone camera, no editing

iPhone clips save as .mov. Open it in CapCut or iMovie and export as above so it's an MP4. On iPhone use Settings → Camera → Formats → Most Compatible for future clips.

Before you send it: watch the exported file once start to finish. Check the sound and that it's 60 seconds or less.
